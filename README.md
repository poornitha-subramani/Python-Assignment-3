# Python Assignment 3 – Loops & Functions

## 📌 Overview

This repository contains three Python programs created as part of my **Python Fundamentals** learning journey.

The assignment focuses on fundamental programming concepts including loops, control statements, functions, user input, random number generation, arithmetic operations, and formatted output.

## 🎯 Programs Included

### 1. Number Guessing Game
A simple interactive game that generates a random number between **1 and 10**. The user gets a maximum of **3 attempts** to guess the correct number.

**Concepts:** `while` loop, `if-elif-else`, `break`, `continue`, `random.randint()`, user input.

### 2. Multiplication Table Generator
A program that accepts a number from the user and generates its multiplication table from **1 to 10**.

**Concepts:** `for` loop, `range()`, arithmetic operations, user input, and f-strings.

### 3. BMI Calculator
A program that calculates **Body Mass Index (BMI)** using a user-defined function.

**Formula:**

`BMI = Weight (kg) / Height (m)²`

**Concepts:** functions, parameters, return statement, floating-point values, arithmetic operations, and formatted output.
