# Python Assignment 3 – Loops & Functions

## About This Project

This repository contains my Python Assignment 3, completed as part of my Python Fundamentals learning journey in Data Analytics.

The assignment focuses on developing a practical understanding of loops, control statements, functions, user input, random number generation, arithmetic operations, and formatted output.

## Objectives

- Understand and apply `while` and `for` loops.
- Practice conditional statements.
- Use `break` and `continue` to control program execution.
- Create and use user-defined functions.
- Work with user input and different data types.
- Perform basic mathematical calculations.
- Develop simple interactive Python programs.
- Improve logical thinking and problem-solving skills.

## Programs Included

### 1. Number Guessing Game

The Number Guessing Game generates a random number between 1 and 10. The user gets a maximum of three attempts to guess the correct number.

The program provides feedback based on the user's guess:

- Too high
- Too low
- Correct guess
- Out-of-range input

Python concepts used:

- While loop
- If, elif, and else
- Break
- Continue
- Random module
- User input
- Comparison and logical operators

### 2. Multiplication Table Generator

The Multiplication Table Generator accepts a number from the user and displays its multiplication table from 1 to 10.

Python concepts used:

- For loop
- Range function
- User input
- Arithmetic operations
- F-strings
- Iteration

### 3. BMI Calculator

The BMI Calculator calculates Body Mass Index using the user's weight and height.

The calculation is performed using a user-defined function.

Formula:

BMI = Weight (kg) / Height (m)²

Python concepts used:

- Functions
- Parameters
- Return statement
- User input
- Float data type
- Arithmetic operations
- F-string formatting
